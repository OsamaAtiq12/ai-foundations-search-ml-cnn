# AI Foundations: Search, Game AI, Classical ML and CNNs

- `Search/`: maze search and A* with visualisation and a comparison of algorithms
- `Minimax/`: Minimax game-playing agent
- `titanic_from_scratch_trees_svm.ipynb`: decision tree and random forest implemented from scratch (about 81% accuracy, matching scikit-learn), plus linear and RBF SVM
- `cnn_vs_resnet18.ipynb`: scratch CNN vs ResNet-18 (71.2% vs 78.0% test accuracy)

Foundations of AI course, MS in AI at LUMS.
